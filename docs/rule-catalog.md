### CAP-001 - Workspace not on a Fabric-capable capacity

*Detection:* Workspace has no dedicated capacity or its SKU cannot host Fabric items (Pro, PPU, A/EM SKUs)

*Remediation:* Assign the workspace to a Fabric (F or trial) or Premium capacity first: Dataflow Gen2 is not available on Pro or PPU workspaces.

### CAP-002 - Capacity not resolvable

*Detection:* capacity_id is set but absent from the capacity APIs (service principals only see some capacities)

*Remediation:* Resolve the capacity manually and confirm it can host Fabric items.

### ECE-001 - Enhanced compute engine enabled

*Detection:* computeEngineBehavior is On

*Remediation:* DirectQuery over dataflows does not exist in Gen2: move DirectQuery consumers to Import or Direct Lake or read the destination tables directly.

### ECE-002 - Enhanced compute engine set to Optimized

*Detection:* computeEngineBehavior is Optimized (default)

*Remediation:* No action: Gen2 uses its own staging compute.

### CON-001 - Unresolved data source connections

*Detection:* The Scanner reports misconfigured datasource usages

*Remediation:* Recreate or rebind the failing connections: the wizard reports Upgrade unavailable until they resolve.

### GW-001 - Source through a data gateway

*Detection:* A source carries a gateway id

*Remediation:* Verify the gateway runs a supported version (latest six releases) and validate or recreate the Fabric connection; OAuth2 credentials on gateway connections fail after one hour.

### LNK-004 - Upstream dataflow not inventoried

*Detection:* Lineage references an upstream dataflow that is not in the inventory (deleted, outside the scan scope or no access)

*Remediation:* Locate the upstream dataflow or fix the broken link: unresolved references make the wizard report Upgrade unavailable.

### DAT-001 - Definition not inspected

*Detection:* The definition could not be collected (no access, not attempted or failed)

*Remediation:* Grant the service principal workspace access or enable deeper collection, then re-run; validate with the Upgrade Wizard assessment.

### OWN-001 - Owner missing or disabled

*Detection:* Owner is empty or the account is disabled (Microsoft Graph enrichment)

*Remediation:* The wizard must be run by the dataflow owner: use Take over, then confirm the Gen1 dataflow refreshes successfully.

### NAM-001 - Name contains unsupported characters

*Detection:* Name has characters other than letters, digits, whitespace and ()[]{}+-=_#

*Remediation:* The wizard strips them automatically; rename first to control the result.

### NAM-002 - Duplicate name in the workspace

*Detection:* Another dataflow of the workspace has the same name

*Remediation:* The wizard prefixes Migrated: rename first.

### STA-001 - Stale and unused

*Detection:* No successful refresh for N days and no downstream consumers

*Remediation:* Decommission candidate: confirm with the owner before spending migration effort.

### DQ-001 - Downstream semantic model uses DirectQuery

*Detection:* A semantic model reading the dataflow has targetStorageMode DirectQuery

*Remediation:* Reconfigure the semantic model to Import or Direct Lake: DirectQuery over dataflows is not supported in Gen2.

### LNK-001 - Contains linked entities

*Detection:* ReferenceEntity / referenceModels, PowerPlatform.Dataflows navigation or Scanner upstreamDataflows

*Remediation:* Cascading refresh through linked entities is not supported in Gen2: upgrade upstream dataflows first and orchestrate refreshes with a pipeline or schedule.

### LNK-002 - Read by other dataflows

*Detection:* Downstream dataflow edges exist

*Remediation:* After the upgrade refresh this dataflow, then open and save each downstream dataflow to rebind it.

### LNK-003 - Consumer uses the legacy PowerBI.Dataflows connector

*Detection:* M text of a downstream dataflow or semantic model contains PowerBI.Dataflows(

*Remediation:* Switch consumers to PowerPlatform.Dataflows: the legacy connector cannot read Gen2 items and the wizard does not detect it.

### REB-001 - Downstream items to re-point after Save-As

*Detection:* Downstream semantic models, reports or dataflows exist

*Remediation:* Save-As creates a new id: re-point every downstream item (effort scales with their number). The wizard keeps the id.

### SEQ-001 - Blocked by an unsupported or deferred upstream dataflow

*Detection:* An upstream dataflow is Unsupported or Deferred

*Remediation:* Resolve the upstream dataflow first: upstream dataflows are migrated before their consumers.

### PIP-001 - Referenced by data pipelines

*Detection:* A pipeline RefreshDataFlow activity references the dataflow

*Remediation:* After Save-As re-point each pipeline activity to the new dataflow id.

### INC-001 - Incremental refresh configured

*Detection:* An entity has an incremental refresh policy (pbi:refreshPolicy)

*Remediation:* Incremental settings are not carried over: define a supporting destination (Lakehouse, Warehouse or Azure SQL Database) and recreate the policy before the first refresh. The source must fold and expose a Date/DateTime column.

### REF-001 - Refresh failing

*Detection:* The latest N refreshes all failed

*Remediation:* Fix the failing refresh first: a healthy Gen1 baseline is needed to validate the migration.

### TRG-001 - External refresh triggers observed

*Detection:* Refresh history shows on-demand or API-triggered runs

*Remediation:* Power Automate flows, scripts and APIs calling the Power BI refresh API must move to the Fabric Job Scheduler API (and to the new id after Save-As).

### SCH-001 - Schedule exceeds 48 runs per day

*Detection:* schedule_runs_per_day is greater than 48

*Remediation:* Gen2 supports up to 48 scheduled refreshes per day.

### SCH-002 - Schedule is copied disabled

*Detection:* The dataflow has an enabled refresh schedule

*Remediation:* Save-As copies the schedule in a disabled state: re-enable it after validation.

### STO-001 - Attached ADLS Gen2 storage (bring your own lake)

*Detection:* modelUrl points to a customer dfs.core.windows.net account, or the workspace has a dataflow storage account

*Remediation:* Wizard: configure an ADLS Gen2 data destination on the upgraded dataflow. Save-As does not move attached-storage data (CDM folders, BYOL): keep on Gen1 or redesign.

### QRY-001 - More than 50 enabled queries

*Detection:* More than 50 enabled (loadEnabled) queries

*Remediation:* Gen2 supports at most 50 queries with staging or a destination: split the dataflow BEFORE upgrading.

### AIX-001 - AI Insights or Azure ML functions

*Detection:* M uses AI.*, CognitiveServices.* or AzureML.* functions

*Remediation:* AI insights are not copied: rebuild with the Fabric AI prompt in Dataflow Gen2.

### CMP-001 - Computed entities

*Detection:* An entity query references another loaded entity of the same dataflow

*Remediation:* Gen2 has no computed-entity engine: validate results and use staged queries or destinations.

### QRY-002 - Close to the 50-query limit

*Detection:* 40 to 50 enabled queries (already reflected in the technical complexity component)

*Remediation:* Plan headroom or split the dataflow.
